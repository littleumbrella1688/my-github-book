# my-github-book
# 普通人的 GitHub 入门

这是一本面向 GitHub 初学者的开源电子书。

## 这本书适合谁

- 刚注册 GitHub 的用户
- 不熟悉 Git 和命令行的用户
- 希望参与开源项目的人

## 你将学到什么

- 创建和管理 GitHub 仓库
- 使用 Markdown 写文档
- 使用 Git 保存版本
- 使用 Issue 和 Pull Request
- 参与开源项目
